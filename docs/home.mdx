Agent Epics extends the Agent Skills standard with stateful, long-running workflows. Skills give agents capabilities. Epics add memory, plans, and lifecycle management.

## Skills: Stateless Capabilities

Agent Skills are folders of instructions, scripts, and resources that agents can discover and use to do things more accurately and efficiently. A skill is a `SKILL.md` file with optional supporting files.

## Epics: Skills + State

Agent Epics build on skills by adding structured state management. Every epic is a valid skill — `SKILL.md` handles routing and instructions, while `EPIC.md` adds stateful workflow context. Epics enable agents to:

- **Resume work across sessions** with plans, state, and activity logs
- **Track progress** through structured state and tactical plans
- **Make decisions** with full context from previous sessions
- **Operate autonomously** with policy constraints, hooks, and cron jobs

## Open development

The Agent Skills format was originally developed by [Anthropic](https://www.anthropic.com/), released as an open standard, and has been adopted by a growing number of agent products. Agent Epics extends the standard with stateful workflow capabilities. Both are open to contributions from the broader ecosystem.

[View on GitHub](https://github.com/agentepics/agentepics)
