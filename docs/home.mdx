Agent Epics is an open format for durable agent systems. It keeps the
portability of `SKILL.md` and adds the state, planning, policy, and lifecycle
machinery needed for reusable workflows, autonomous operators, installed
capabilities, and the durable state containers that hold them over time.

[Why state and reuse matter](/stateful-and-reusable) shows where a plain skill
falls short, with concrete website, book, and feature-film examples.

[Worked example](/epic-creation/worked-example) shows one reusable website
epic from authoring through the plans, state, logs, and artifacts the agent
creates during use.

## Why Epics

Every epic is still a valid `SKILL.md` package, but Epics add the pieces that
plain skills do not have. `SKILL.md` handles routing and instructions, while
`EPIC.md` and the EPIC file set add durable operating context and durable
working state. Epics enable agents to:

- **Resume work across sessions** with plans, state, and activity logs
- **Keep durable state containers** for facts, decisions, milestones, and work
  that must survive outside the current chat
- **Package reusable workflows** that can be run again with fresh working state
- **Install durable capabilities** such as memory, integrations, or monitors
- **Run several operating loops at once** through plans, recurring jobs,
  continuous state, and event-driven hooks
- **Track progress** through structured state and tactical plans
- **Make decisions** with full context from previous sessions
- **Operate autonomously** with policy constraints, hooks, and cron jobs

## Ecosystem foundation

Many agent products already understand `SKILL.md`. That compatibility layer
makes EPIC adoption easier and keeps epics portable across tools.

<LogoCarousel />

## Open development

`SKILL.md` was originally developed by
[Anthropic](https://www.anthropic.com/), released as an open format, and
adopted across a growing set of agent products. Agent Epics builds on that
substrate and is maintained here by Kindship.ai.

[View on GitHub](https://github.com/agentepics/agentepics)
